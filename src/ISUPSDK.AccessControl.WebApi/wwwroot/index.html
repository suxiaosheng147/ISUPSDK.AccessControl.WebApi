使用前先填顶部三项

API 基址
KrAdmin.API 的地址，例如 https://localhost:5001（不要带结尾斜杠）
Token
登录 KrAdmin 拿到的 access_token，请求会带上 Authorization: bearer <token>
环境
对应配置库里的 RemoteServiceConfig.Environment（PROD / UAT / TEST / DEV）；留空由服务端按宿主环境判定

页面只负责调接口，配置保存在浏览器 localStorage（换浏览器或清缓存需要重新填）。

连通性检查

接口清单（12 个资源 / 85 个接口）

全部接口都是 REST 风格：路径只用名词，动作交给 HTTP 方法（GET / POST / PUT / PATCH / DELETE）。 分页统一使用 pageSize / pageIndex（首页从 1 开始），返回 PageModel<T>。
