门禁事件查询

数据来源：GET /api/events（消息队列消费后写入 EventStore 的事件）；时间均为北京时间。

链路状态（队列 → 消费者 → 数据库）

查询条件

时间留空表示不限；填值按北京时间解释（无需写时区）。

查询结果

ID 事件时间 设备 主类型 次类型 工号 姓名 卡号 门号 认证方式 来源 门禁 队列 投递 操作
运维操作：手工补录事件 / 手动对账补漏 / 重放落盘文件

手工补录（POST /api/events/manual）

默认走 去重 → 落盘 → 消息队列 → 入库；示例：漏报补录、从旧系统导入历史通行记录。

手动对账补漏（POST /api/events/reconcile）

填了开始/结束时间就按该区间补历史（只填开始=补到"现在"；只填结束=按"回看秒数"从结束时间往前推）； 两者都不填则按"回看秒数"从当前时间往前推。时间不带时区，按服务端 ISUP:Time:TimeZone（默认北京时间）解释。 补历史区间不会推进后台定时对账的进度。

重放落盘文件（POST /api/events/replay-spool）

把落盘 JSONL 中尚未入库的事件补入库（按去重键幂等，不会产生重复行）。
